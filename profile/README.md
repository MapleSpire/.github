**MapleSpire** keeps one model of your systems — people, software systems,
containers, components and the relationships between them — and every diagram
is a view of that model. Rename a service once and every diagram, table and
export follows.

- **Model, not just draw** — C4 levels with drill-down, automatic layout, 2D and 3D model viewers
- **Work together** — real-time collaboration, offline-first sync, drafts with three-way merge, decision records
- **Share and govern** — organisations, roles and SSO, interactive share links, Structurizr import, a dozen export formats
- **Extend it** — AI assistant with your own provider key, an MCP server for agents, theme plugins

Free and open source under the AGPL-3.0. Try it on your machine in a few minutes
with Docker: [getting started](https://github.com/MapleSpire/maplespire/blob/main/docs/getting-started.md).
